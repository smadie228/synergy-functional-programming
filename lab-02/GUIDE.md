## Подготовка компьютера

1. Установите [Python 3](https://www.python.org/downloads/) и [Visual Studio Code](https://code.visualstudio.com/).
2. В VS Code установите расширение **Python** от Microsoft.
3. Скачайте [репозиторий](https://github.com/smadie228/synergy-functional-programming) через **Code → Download ZIP**, распакуйте его.
4. В меню **File → Open Folder** выберите нужную папку лабораторной.
5. Откройте **Terminal → New Terminal**. Проверьте интерпретатор:

```powershell
py --version
```

Если `py` не найден, попробуйте `python --version`. В VS Code можно выбрать интерпретатор через **Ctrl+Shift+P → Python: Select Interpreter**.

> [!TIP]
> Файлы из архива нужно **распаковать**. Если программа не находит другой файл, проверьте, что терминал открыт именно в папке нужной лабораторной.


## Запуск лабораторной № 2

Откройте папку `lab-02` в VS Code. Введите команды **по очереди**:

```powershell
py lab2_block1.py
py lab2_block2.py
py lab2_block3.py
```

> [!IMPORTANT]
> Для этих исходников необходим только стандартный Python. Не требуется устанавливать сторонние пакеты через `pip`.

## Разбираем задания

### Блок 1 — функции высшего порядка

Функция высшего порядка принимает другую функцию или возвращает функцию в результате.

**Задача для самостоятельной практики:** напишите собственную функцию `my_map(f, xs)` без встроенного `map`. Передайте функцию возведения в квадрат и список `[1, 2, 3]`. Ожидаемый результат: `[1, 4, 9]`.

В исходнике также рассмотрены каррирование, композиция функций и замыкания.

### Блок 2 — λ-исчисление

Лямбда-исчисление описывает функции через λ-выражения. Основные понятия:

- **α-эквивалентность** — одинаковое строение терма с другими именами связанных переменных;
- **β-редукция** — применение функции к аргументу;
- **η-преобразование** — упрощение эквивалентной записи функции при соблюдении условий.

Например, `(λx. x) y → y`.

Программа `lab2_block2.py` содержит представление термов, разбор текста, поиск переменных и стратегии редукции. Не ждите, что любой терм обязательно имеет нормальную форму: некоторые выражения могут редуцироваться бесконечно.

### Блок 3 — комбинаторы

Комбинатор — функция без свободных переменных. В лабораторной рассматриваются `I`, `K`, `S`, `B`, `C` и `Y`.

**Практика:** разберите отдельно `I(x) = x` и `K(x)(y) = x`. Затем попробуйте проследить, как в коде устроено применение Y-комбинатора к рекурсивным вычислениям.


## Как проверять себя

1. Сначала прочитайте формулировку упражнения.
2. Напишите свой вариант решения в отдельном файле (не изменяя исходный пример).
3. Протестируйте обычные и крайние случаи: нули, пустые списки, неверные данные.
4. Запустите исходный блок и сравните результаты и структуру решения.
5. Убедитесь, что понимаете, **почему** получился именно такой ответ.

## Что делать, если программа не запускается

| Ситуация | Что проверить |
|:---|:---|
| `py` / `python` не распознаётся | Установлен ли Python, включён ли он в PATH; попробуйте перезапустить терминал |
| `can't open file` | Совпадает ли имя файла; находится ли терминал в нужной папке |
| `SyntaxError` | Проверьте версию Python, отступы и случайно изменённые символы |
| `NameError` | Проверьте имена переменных и порядок определения функций |
| `AssertionError` | Сравните фактический и ожидаемый результат; проверьте входные данные |
| В VS Code вывод отличается от терминала | Проверьте, какой интерпретатор выбран в VS Code |

Справочные ошибки в этой таблице — **типичные ситуации**, а не утверждение, что они возникали при выполнении сохранённых исходников.
