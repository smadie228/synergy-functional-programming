## С чего начать

Если вы ещё не работали с Haskell, откройте **[пошаговое руководство по лабораторной № 4](lab-04/GUIDE.md)**. В нём разобраны установка GHC, запуск тестов, типичные ошибки и сами задания.

Если компилятор уже установлен, достаточно открыть папку `lab-04` в терминале и выполнить:

```bash
runghc Main.hs
```

В этой работе предусмотрено **34 автоматические проверки**, которые были успешно выполнены на GHC 9.10.3 в Windows и GHC 8.10.6 в Replit.
