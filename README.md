## Как устроены папки

```text
synergy-functional-programming/
├── lab-01/     Python: основы, чистые функции и unittest
├── lab-02/     Python: функции высшего порядка и λ-исчисление
├── lab-03/     Python: сопоставление с образцом, замыкания и CPS
└── lab-04/     Haskell: рекурсия, ленивые списки и RPN
```

У каждой лабораторной единый подход к оформлению:

- **README.md** — цель, задания, команды, результаты и галерея;
- **GUIDE.md** — пошаговое обучение и практика для самостоятельного решения;
- **исходники** — программы на языке соответствующей работы;
- **images/** — реальные скриншоты кода и результатов, когда они предусмотрены.

## Быстрый запуск

### Python — лабораторные № 1–3

Установите [Python](https://www.python.org/downloads/) и откройте соответствующую папку в терминале. Например, для первой лабораторной:

```powershell
py --version
py lab1.py
py lab1_block5.py
```

**14 unit-тестов** первой лабораторной прошли успешно при проверке исходных файлов. Лабораторные № 2 и № 3 также выполнены без ошибок завершения.

### Haskell — лабораторная № 4

Установите GHC через [GHCup](https://www.haskell.org/ghcup/install/). В папке `lab-04`:

```powershell
ghc --version
runghc Main.hs
```

Для четвёртой лабораторной предусмотрено **34 теста**, успешно пройденных в Windows и Replit.

[Ошибки, с которыми столкнулись при настройке GHC и Replit](lab-04/ERRORS.md)
